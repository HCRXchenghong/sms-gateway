# VoiceSMS Gateway v1.2.0

## What changed

- Fixed call state reconciliation when the far end hangs up during ringing or the realtime socket misses an event. The app now closes the stale call screen and shows the ending reason.
- Added per-call recording controls in the app and web console, including optional announcement, recording status, and playback from call history.
- Fixed real audio capture: capture tools now write to the shared audio stream correctly, and header-only WAV files are reported as failed instead of appearing as recordings.
- Added AI phone tasks, live translation modes, call summaries, and controls for configuring providers and backup endpoints.
- Added app boot autostart control in the admin console and made two-factor authentication opt-in so an administrator can enable it after login.
- Updated the Flutter dialer and navigation to follow the Samsung phone app's visual style.
