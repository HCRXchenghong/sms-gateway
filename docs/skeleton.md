## 通用元素需要设计

- **按钮**：主 / 次 / 危险 / 文字链接 4 种 × 默认/悬停/禁用/加载中 4 状态
- **输入框**：默认 / 聚焦 / 错误 / 禁用 4 状态
- **chip**：成功（绿）/ 失败（红）/ 进行中（蓝）/ 中性（灰）
- **toast**：3 色短弹（成功/失败/信息）右上角或顶部，3 秒消失
- **modal**：撤销 Key 二次确认用
- **明暗主题**：每个元素都给两套色

## 颜色 / 字号 / 间距给个数即可

```
颜色（明 / 暗 各给 9 个 HEX）：
  bg / surface / surface-2 / border / text / text-muted / accent / success / danger

字号：12 / 14 / 16 / 18 / 22 / 28 px

间距：4 / 8 / 12 / 16 / 24 / 32 / 48 px

圆角：按钮和输入框 8px，卡片 12px
```
